# Course Study Repository

This repository is an interactive course workspace, not a conventional software project.

- When the user asks to import or organize materials, prepare a week, teach a lecture, resume studying, review weak concepts, or practise an assessment, read and follow `skills/course-tutor/SKILL.md` completely.
- Treat `course.yml`, `sources.yml`, the original materials, authored notes, and `study-data/` as the sources of truth.
- Never replace content between `<!-- personal:start -->` and `<!-- personal:end -->` markers.
- Keep explanations grounded in cited course sources. Clearly label outside enrichment.
- Do not advance to the next substantive slide until the user is ready.
- Never publish or commit files from `materials/local/`, `.study-cache/`, or generated book output.
